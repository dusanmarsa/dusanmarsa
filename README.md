#### Experiments

- **[indox](https://github.com/dusanmarsa/indox)** - AI Knowledgebase with adapters for GitHub and Notion. Required data is pulled from adapters, chunked, embedded and saved to vector database. After that user is able to either use chat UI or MCP server to get the information from the single source with semantic search.
- **[validvision](https://valid.vision)** — multi-persona AI panel that pressure-tests startup ideas. Built with Mastra workflows, web search via Exa, real-time streaming transcript in Next.js.
- **[ai-harness](https://github.com/dusanmarsa/ai-harness)** — minimal agent-loop harness with tools and semantic vector memory that indexes a codebase and retrieves relevant files on demand.
